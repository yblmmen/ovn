Service External-IP 활용 & L2 Announcement

온프레미스/IDC 환경에서 MetalLB 없이 CiliumLoadBalancerIPPool로 LoadBalancer IP를 할당하고, CiliumL2AnnouncementPolicy(ARP + Lease)로 외부에 노출하는 방법입니다.

Cilium Service LB-IPAM (CiliumLoadBalancerIPPool)

IDC 환경에서는 MetalLB 등이 없으면 type: LoadBalancer 서비스가 <pending> 상태에 머뭅니다. Cilium에서는 CiliumLoadBalancerIPPool(lbippool) 객체로 IP 풀을 선언해 자동으로 EXTERNAL-IP를 할당할 수 있습니다.

yaml
apiVersion: "cilium.io/v2" # v1.17 : cilium.io/v2alpha1
kind: CiliumLoadBalancerIPPool
metadata:
  name: "cilium-lb-ippool"
spec:
  blocks:
    - start: "192.168.10.211"
      stop: "192.168.10.215"

배포 즉시 EXTERNAL-IP가 할당되며, cilium-dbg service list에서 EXTERNAL-IP와 각 Pod Endpoint 매핑을 확인할 수 있습니다. 단, 클러스터 외부 라우터는 아직 이 IP의 위치를 모르기 때문에 L2 Announcement 또는 BGP가 필요합니다.

Cilium L2 Announcement 설정 및 Lease 동작 원리

같은 L2 네트워크 대역에서 ARP로 EXTERNAL-IP를 광고하기 위해 l2announcements.enabled=true를 활성화하고 CiliumL2AnnouncementPolicy를 배포합니다.

bash
helm upgrade cilium cilium/cilium --namespace kube-system --version 1.18.0 --reuse-values \
  --set l2announcements.enabled=true
kubectl rollout restart -n kube-system ds/cilium
yaml
apiVersion: "cilium.io/v2alpha1"
kind: CiliumL2AnnouncementPolicy
metadata:
  name: policy1
spec:
  serviceSelector:
    matchLabels:
      app: webpod
  nodeSelector:
    matchExpressions:
      - key: kubernetes.io/hostname
        operator: NotIn
        values:
          - k8s-w0
  interfaces:
    - ^eth[1-9]+
  externalIPs: true
  loadBalancerIPs: true
bash
# Lease 리더 선출 확인
kubectl get lease
# NAME                                  HOLDER   AGE
# cilium-l2announce-kube-system-webpod  k8s-w1   16s

# 라우터에서 ARP 확인 -> 192.168.10.212가 k8s-w1의 MAC 주소로 등록됨
arp -a
