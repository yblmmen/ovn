Service External-IP 활용 & L2 Announcement

온프레미스/IDC 환경에서 MetalLB 없이 CiliumLoadBalancerIPPool로 LoadBalancer IP를 할당하고, CiliumL2AnnouncementPolicy(ARP + Lease)로 외부에 노출하는 방법입니다.

Cilium Service LB-IPAM (CiliumLoadBalancerIPPool)

IDC 환경에서 별도 CNI나 MetalLB가 없으면 LoadBalancer 타입 서비스의 EXTERNAL-IP가 <pending> 상태가 됩니다. Cilium의 CiliumLoadBalancerIPPool(lbippool)은 CIDR, start/stop 블록, serviceSelector 라벨 조건 등으로 IP 풀을 지정해 EXTERNAL-IP를 자동 할당합니다.

yaml
apiVersion: "cilium.io/v2" # v1.17 : cilium.io/v2alpha1
kind: CiliumLoadBalancerIPPool
metadata:
  name: "cilium-lb-ippool"
spec:
  blocks:
    - start: "192.168.10.211"
      stop: "192.168.10.215"

배포 후 cilium-dbg service list를 보면 EXTERNAL-IP와 각 Pod Endpoint가 매핑된 것을 확인할 수 있습니다. 다만 외부 라우터는 아직 이 IP의 경로를 모르므로 통신이 안 되며, 이를 위해 L2 Announcement나 BGP가 필요합니다.

Cilium L2 Announcement 설정 및 ARP/Lease 동작

bash
helm upgrade cilium cilium/cilium --namespace kube-system --version 1.18.0 --reuse-values \
  --set l2announcements.enabled=true
kubectl rollout restart -n kube-system ds/cilium
k get cm cilium-config -oyaml | grep enable-l2
yaml
apiVersion: "cilium.io/v2alpha1"
kind: CiliumL2AnnouncementPolicy
metadata:
  name: policy1
spec:
  serviceSelector:
    matchLabels:
      app: webpod
  nodeSelector:
    matchExpressions:
      - key: kubernetes.io/hostname
        operator: NotIn
        values:
          - k8s-w0
  interfaces:
    - ^eth[1-9]+
  externalIPs: true
  loadBalancerIPs: true
bash
kubectl get lease
# NAME                                  HOLDER   AGE
# cilium-l2announce-kube-system-webpod  k8s-w1   16s

# router 노드에서 ARP 확인 -> 192.168.10.212가 k8s-w1 MAC 주소로 등록됨
arping -i eth1 $LBIP -c 1000
arp -a
