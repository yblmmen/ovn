Hubble Flow Logs 수집 및 Loki 시각화

Hubble Export로 노드에 저장된 Flow Log(/var/run/cilium/hubble/events.log)를 Promtail + Loki Stack으로 수집해 Grafana에서 조회하는 심화 과제입니다.

Loki + Promtail + Grafana 아키텍처

Hubble Flow Logs를 중앙 로깅 시스템으로 수집·시각화하기 위해 loki-stack을 Helm으로 배포합니다. Promtail이 DaemonSet으로 각 노드의 /var/run/cilium/hubble 경로를 hostPath로 마운트해 events.log를 읽어 Loki로 전송합니다.

yaml
# helm template loki grafana/loki-stack -f ./values.yaml -n monitoring
promtail:
  enabled: true
  extraVolumes:
    - name: cilium-hubble-logs
      hostPath:
        path: /var/run/cilium/hubble
        type: DirectoryOrCreate
  extraVolumeMounts:
    - name: cilium-hubble-logs
      mountPath: /var/run/cilium/hubble
      readOnly: true
  config:
    snippets:
      scrapeConfigs: |
        - job_name: cilium-export-log
          static_configs:
            - targets:
                - localhost
              labels:
                job: cilium-export-log
                __path__: /var/run/cilium/hubble/events.log
      logLevel: info
      serverPort: 3101
      clients:
        - url: http://{{ .Release.Name }}:3100/loki/api/v1/push

Grafana Loki Datasource 연동 및 트러블슈팅 메모

  • Grafana Datasource에 Loki 서비스 주소(네임스페이스 포함, TCP 3100)를 등록한 뒤 Save & Test를 실행합니다.
  • 만약 cilium-monitoring 네임스페이스에 이전에 적용한 CNP가 남아 있다면 Loki(monitoring 네임스페이스) 호출이 차단될 수 있으므로 주의해야 합니다.
  • loki-stack 차트는 유지보수가 중단되어 라벨 파서 분리가 잘 동작하지 않는 경우가 있어, 실무에서는 별도 promtail Helm 차트 사용이 권장됩니다.
