Hubble Flow Logs 수집 및 Loki 시각화

Hubble Export로 노드에 저장된 Flow Log(/var/run/cilium/hubble/events.log)를 Promtail + Loki Stack으로 수집해 Grafana에서 조회하는 심화 과제입니다.

loki-stack 설치 및 Promtail hostPath 마운트

Promtail이 DaemonSet으로 설치되어 각 노드의 /var/run/cilium/hubble/events.log를 hostPath로 읽어 Loki로 전송합니다.

yaml
# helm template loki grafana/loki-stack -f ./values.yaml -n monitoring
promtail:
  enabled: true
  extraVolumes:
    - name: cilium-hubble-logs
      hostPath:
        path: /var/run/cilium/hubble
        type: DirectoryOrCreate
  extraVolumeMounts:
    - name: cilium-hubble-logs
      mountPath: /var/run/cilium/hubble
      readOnly: true
  config:
    snippets:
      scrapeConfigs: |
        - job_name: cilium-export-log
          static_configs:
            - targets:
                - localhost
              labels:
                job: cilium-export-log
                __path__: /var/run/cilium/hubble/events.log
      logLevel: info
      serverPort: 3101
      clients:
        - url: http://{{ .Release.Name }}:3100/loki/api/v1/push

Grafana Loki Datasource 연동 및 주의사항

  • Loki가 다른 네임스페이스(monitoring)에 있으므로 Datasource URL에 네임스페이스까지 정확히 입력해 Save & Test를 수행합니다.
  • 이전 실습에서 cilium-monitoring에 CNP를 적용해두고 삭제하지 않으면 Loki(3100)로의 연결이 차단(Drop)됩니다.
  • loki-stack 차트는 유지보수가 중단되어 라벨 파서 분리가 매끄럽지 않으므로 별도 promtail 차트를 사용하는 것이 권장됩니다.
