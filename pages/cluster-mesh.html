Cilium Cluster Mesh 다중 클러스터 연동

west와 east 두 개의 kind 클러스터를 Cluster Mesh로 연결해 NAT 없는 Pod-to-Pod 통신과 글로벌 서비스(affinity=local/remote, shared) 제어를 실습합니다.

다중 클러스터 환경 구성 및 nonMasqueradeCIDRs

west(PodCIDR 10.0.0.0/16, cluster.id=1)와 east(PodCIDR 10.1.0.0/16, cluster.id=2) 클러스터를 생성합니다. 핵심은 각 클러스터의 ipv4NativeRoutingCIDR에는 본인 PodCIDR를, ipMasqAgent.config.nonMasqueradeCIDRs에는 상대 클러스터의 PodCIDR를 지정해 클러스터 간 통신 시 NAT를 하지 않도록 하는 것입니다.

bash
# west 클러스터 설치 예시
cilium install --version 1.17.6 --set ipam.mode=kubernetes \
  --set kubeProxyReplacement=true --set bpf.masquerade=true \
  --set routingMode=native --set autoDirectNodeRoutes=true \
  --set ipv4NativeRoutingCIDR=10.0.0.0/16 \
  --set ipMasqAgent.enabled=true --set ipMasqAgent.config.nonMasqueradeCIDRs='{10.1.0.0/16}' \
  --set cluster.name=west --set cluster.id=1 --context kind-west

Cluster Mesh 3단계 연결 (CA 동기화 → Enable → Connect)

bash
# 1. TLS CA 인증서 동기화 (west -> east)
kubectl --context kind-east delete secret -n kube-system cilium-ca
kubectl --context kind-west get secret -n kube-system cilium-ca -o yaml | kubectl --context kind-east create -f -

# 2. Mesh 활성화
cilium clustermesh enable --service-type NodePort --enable-kvstoremesh=false --context kind-west
cilium clustermesh enable --service-type NodePort --enable-kvstoremesh=false --context kind-east

# 3. Mesh 연결 및 상태 확인
cilium clustermesh connect --context kind-west --destination-context kind-east
cilium clustermesh status --context kind-west --wait

연결이 완료되면 두 클러스터의 커널 라우팅 테이블에 상대 클러스터의 PodCIDR 경로가 추가되며, Hubble에서도 원격 클러스터 이름(west/east)이 함께 표시됩니다.

Global Service와 affinity=local 운영 전략

서비스에 service.cilium.io/global: "true"를 붙이면 namespace + service name이 동일한 양 클러스터의 Endpoint가 통합됩니다. 다만 기본값에서는 로컬 클러스터와 원격 클러스터로 트래픽이 골고루 분산되므로 지연과 대역폭 비용을 줄이려면 affinity: local을 함께 지정하는 것이 좋습니다.

yaml
apiVersion: v1
kind: Service
metadata:
  name: webpod
  annotations:
    service.cilium.io/global: "true"
    service.cilium.io/affinity: "local"   # 로컬 우선 (장애 시 원격 페일오버), remote도 가능
    service.cilium.io/shared: "true"      # false 설정 시 해당 클러스터 Endpoint 비공유
