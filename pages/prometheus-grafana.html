Prometheus/Grafana를 통한 Cilium 가시성 확보

Cilium·Operator·Hubble의 메트릭 포트를 활성화해 Prometheus로 수집하고, Grafana 대시보드 시각화 및 L7 민감정보 마스킹(--hubble-redact)을 적용합니다.

실습 환경 구성 및 NodePort 노출

Cilium 공식 monitoring-example.yaml과 테스트용 webpod(2 replicas, podAntiAffinity), curl-pod를 배포한 뒤 Prometheus(30001)와 Grafana(30002)를 NodePort로 변경합니다.

bash
kubectl apply -f https://raw.githubusercontent.com/cilium/cilium/1.17.6/examples/kubernetes/addons/prometheus/monitoring-example.yaml

cat << EOF | kubectl apply -f -
apiVersion: apps/v1
kind: Deployment
metadata:
  name: webpod
spec:
  replicas: 2
  selector:
    matchLabels:
      app: webpod
  template:
    metadata:
      labels:
        app: webpod
    spec:
      affinity:
        podAntiAffinity:
          requiredDuringSchedulingIgnoredDuringExecution:
            - labelSelector:
                matchExpressions:
                  - key: app
                    operator: In
                    values:
                      - sample-app
              topologyKey: "kubernetes.io/hostname"
      containers:
        - name: webpod
          image: traefik/whoami
          ports:
            - containerPort: 80
---
apiVersion: v1
kind: Service
metadata:
  name: webpod
  labels:
    app: webpod
spec:
  selector:
    app: webpod
  ports:
    - protocol: TCP
      port: 80
      targetPort: 80
  type: ClusterIP
EOF

kubectl patch svc -n cilium-monitoring grafana -p '{"spec": {"type": "NodePort", "ports": [{"port": 3000, "targetPort": 3000, "nodePort": 30002}]}}'
kubectl patch svc -n cilium-monitoring prometheus -p '{"spec": {"type": "NodePort", "ports": [{"port": 9090, "targetPort": 9090, "nodePort": 30001}]}}'

Cilium Prometheus 메트릭 포트 활성화

  • prometheus.enabled=true: Cilium Agent에서 TCP 9962 노출
  • operator.prometheus.enabled=true: Cilium Operator에서 TCP 9963 노출
  • hubble.metrics.enabled: Hubble에서 TCP 9965 노출
bash
helm upgrade --install cilium cilium/cilium --version 1.17.6 --reuse-values \
  --namespace kube-system \
  --set prometheus.enabled=true \
  --set operator.prometheus.enabled=true \
  --set hubble.enabled=true \
  --set hubble.metrics.enableOpenMetrics=true \
  --set hubble.metrics.enabled="{dns,drop,tcp,flow,port-distribution,icmp,httpV2:exemplars=true;labelsContext=source_ip\,source_namespace\,source_workload\,destination_ip\,destination_namespace\,destination_workload\,traffic_direction}"

Prometheus는 Pod Annotation을 기반으로 Pull 수집하며, 메트릭이 안 보일 때는 1) Pod Annotation, 2) Prometheus Status 타깃 수집 상태를 확인합니다. Grafana에서는 커뮤니티 대시보드 JSON Import 및 PromQL(rate, sum by, topk)로 시각화합니다.

Hubble L7 데이터 확인 & 민감정보 제외 (Redact)

l7-visibility CNP를 적용하면 Hubble에서 HTTP Path와 Query까지 노출되는 문제가 생깁니다. 이때 --hubble-redact-enabled와 --hubble-redact-http-urlquery를 적용하면 Path 파라미터는 유지하면서 민감한 Query 파라미터는 제외할 수 있습니다.

yaml
apiVersion: "cilium.io/v2"
kind: CiliumNetworkPolicy
metadata:
  name: "l7-visibility"
spec:
  endpointSelector:
    matchLabels:
      "k8s:io.kubernetes.pod.namespace": cilium-monitoring
  egress:
    - toPorts:
        - ports:
            - port: "53"
              protocol: ANY
          rules:
            dns:
              - matchPattern: "*"
    - toEndpoints:
        - matchLabels:
            "k8s:io.kubernetes.pod.namespace": cilium-monitoring
      toPorts:
        - ports:
            - port: "80"
              protocol: TCP
            - port: "8080"
              protocol: TCP
          rules:
            http: [{}]
bash
helm upgrade cilium cilium/cilium --namespace kube-system --reuse-values \
  --set extraArgs="{--hubble-redact-enabled,--hubble-redact-http-urlquery}"
