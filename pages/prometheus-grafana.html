Prometheus/Grafana를 통한 Cilium 가시성 확보

Cilium·Operator·Hubble의 OpenMetrics 포트를 활성화해 Prometheus로 수집하고, Grafana 대시보드 시각화 및 L7 민감정보 마스킹(--hubble-redact)을 적용합니다.

모니터링 실습 환경 및 Cilium 메트릭 활성화

Cilium 공식 monitoring-example.yaml과 테스트용 webpod, curl-pod를 배포하고 Grafana(30002), Prometheus(30001)를 NodePort로 노출합니다.

bash
kubectl apply -f https://raw.githubusercontent.com/cilium/cilium/1.17.6/examples/kubernetes/addons/prometheus/monitoring-example.yaml

kubectl patch svc -n cilium-monitoring grafana -p '{"spec": {"type": "NodePort", "ports": [{"port": 3000, "targetPort": 3000, "nodePort": 30002}]}}'
kubectl patch svc -n cilium-monitoring prometheus -p '{"spec": {"type": "NodePort", "ports": [{"port": 9090, "targetPort": 9090, "nodePort": 30001}]}}'

Cilium은 기본적으로 Prometheus 메트릭을 노출하지 않으므로 Helm 옵션으로 각 컴포넌트 포트를 열어줍니다.

  • prometheus.enabled=true: cilium-agent에서 TCP 9962 노출
  • operator.prometheus.enabled=true: cilium-operator에서 TCP 9963 노출
  • hubble.metrics.enabled: Hubble에서 TCP 9965 노출
bash
helm upgrade --install cilium cilium/cilium --version 1.17.6 --reuse-values \
  --namespace kube-system \
  --set prometheus.enabled=true \
  --set operator.prometheus.enabled=true \
  --set hubble.enabled=true \
  --set hubble.metrics.enableOpenMetrics=true \
  --set hubble.metrics.enabled="{dns,drop,tcp,flow,port-distribution,icmp,httpV2:exemplars=true;labelsContext=source_ip\,source_namespace\,source_workload\,destination_ip\,destination_namespace\,destination_workload\,traffic_direction}"

Prometheus & Grafana 데이터 확인

Prometheus는 Pod Annotation을 기반으로 Pull 방식 시계열 메트릭을 수집합니다. 보고자 하는 메트릭이 안 보일 때는 1) Pod Annotation, 2) Prometheus Status 타깃 수집 상태를 우선 확인합니다. Grafana에서는 JSON Import로 커뮤니티 대시보드를 쉽게 추가할 수 있으며 PromQL(rate, sum by, topk)로 집계합니다.

Hubble L7 가시성과 민감정보 마스킹 (Redact)

L7 가시성을 위해 l7-visibility CNP를 적용하면 HTTP 요청 Path와 Query 정보까지 Hubble에 노출되는 문제가 생깁니다. 이때 --hubble-redact-enabled 및 --hubble-redact-http-urlquery 옵션을 주면 Path 파라미터는 유지하되 민감한 Query 파라미터는 마스킹할 수 있습니다.

yaml
apiVersion: "cilium.io/v2"
kind: CiliumNetworkPolicy
metadata:
  name: "l7-visibility"
spec:
  endpointSelector:
    matchLabels:
      "k8s:io.kubernetes.pod.namespace": cilium-monitoring
  egress:
    - toPorts:
        - ports:
            - port: "53"
              protocol: ANY
          rules:
            dns:
              - matchPattern: "*"
    - toEndpoints:
        - matchLabels:
            "k8s:io.kubernetes.pod.namespace": cilium-monitoring
      toPorts:
        - ports:
            - port: "80"
              protocol: TCP
            - port: "8080"
              protocol: TCP
          rules:
            http: [{}]
bash
helm upgrade cilium cilium/cilium --namespace kube-system --reuse-values \
  --set extraArgs="{--hubble-redact-enabled,--hubble-redact-http-urlquery}"
