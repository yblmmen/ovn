Service Mesh Gateway API Support

Ingress의 한계를 넘어 역할 분리(GatewayClass·Gateway·HTTPRoute/TLSRoute), TLS Terminate/Passthrough, 가중치 분배(Weight), 헤더 수정(RequestHeaderModifier)을 구현합니다.

Ingress vs Gateway API 비교

구분IngressGateway API
지원 프로토콜HTTP, HTTPS 중심HTTP, HTTPS, gRPC, TCP, UDP
리소스 모델단일 Ingress 객체GatewayClass / Gateway / Route 등 CRD 분리
라우팅 정책Host + Path 중심Host + Path + Method + Header + Query + Rate

Gateway API는 Ingress Controller와 공존이 불가하므로 ingressController.enabled=false --set gatewayAPI.enabled=true로 전환하고 Gateway API CRD 6종을 설치합니다.

HTTPRoute · TLS Terminate / Passthrough · Weight & Header

yaml
apiVersion: gateway.networking.k8s.io/v1
kind: Gateway
metadata:
  name: my-gateway
spec:
  gatewayClassName: cilium
  listeners:
    - protocol: HTTP
      port: 80
      name: web-gw
      allowedRoutes:
        namespaces:
          from: Same
---
apiVersion: gateway.networking.k8s.io/v1
kind: HTTPRoute
metadata:
  name: example-route-1
spec:
  parentRefs:
    - name: my-gateway
  rules:
    - matches:
        - path:
            type: PathPrefix
            value: /
      filters:
        - type: RequestHeaderModifier
          requestHeaderModifier:
            add:
              - name: my-header-name
                value: my-header-value
      backendRefs:
        - name: echo-1
          port: 80
          weight: 90
        - name: echo-2
          port: 80
          weight: 10

End-to-End 암호화가 필요한 경우 Gateway 리스너에 protocol: TLS, tls.mode: Passthrough를 설정하고 TLSRoute를 연결하면 Gateway에서 복호화하지 않고 Backend(Nginx 등)까지 암호화된 트래픽을 그대로 전달합니다.
