MTU 1450의 의미와 캡슐화 오버헤드

VXLAN/GENEVE 터널 모드에서 라우팅 MTU가 1450으로 설정되는 이유(50바이트 캡슐화 오버헤드)와 PMTUD Black Hole, MSS Clamping 등 실무 주의사항을 정리합니다.

MTU와 MSS의 정의, 그리고 VXLAN 50바이트 오버헤드

  • MTU (Maximum Transmission Unit): L3 인터페이스가 단편화 없이 한 번에 보낼 수 있는 최대 IP 패킷 크기 (표준 이더넷 = 1500 bytes).
  • MSS (Maximum Segment Size): L4 TCP 헤더를 제외한 순수 페이로드 최대 크기 (3-Way Handshake 시 협상).
  • VXLAN 패킷 구조: Outer MAC(14B) + Outer IP(20B) + UDP(8B) + VXLAN Header(8B) = 총 50바이트 오버헤드. 따라서 단편화 없이 통과하려면 내부 IP MTU는 1500 - 50 = 1450 bytes가 됩니다.

실무 주의사항: PMTUD Black Hole & MSS Clamping

Path MTU Discovery(PMTUD)는 IP 헤더의 DF(Don't Fragment) 비트를 켜고 경로상 작은 MTU를 만나면 ICMP Fragmentation Needed (Type 3, Code 4) 응답을 받아 크기를 줄입니다. 하지만 방화벽에서 ICMP를 차단하면 패킷이 조용히 드롭되는 PMTUD Black Hole이 발생합니다. 이를 방지하려면 ICMP Type 3 Code 4를 허용하거나 MSS Clamping 또는 인터페이스 MTU 사전 하향을 적용해야 합니다.
