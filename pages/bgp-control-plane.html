Cilium Native + BGP Control Plane 활용

FRR 라우터와 BGP 피어링을 맺어 PodCIDR, LoadBalancer IP, ClusterIP를 광고하고 externalTrafficPolicy(Cluster vs Local)에 따른 패킷 경로 차이를 검증합니다.

Cilium BGP Control Plane 구조

Native 모드에서 autoDirectNodeRoutes=false일 때 외부 라우터(FRR)와 BGP 피어링을 맺어 라우팅 테이블을 동적으로 교환합니다. Cilium BGP는 4개의 CRD로 구성됩니다.

  • CiliumBGPClusterConfig: 클러스터 단위로 BGP 인스턴스 및 피어를 정의
  • CiliumBGPNodeConfigOverride: 특정 노드에만 다른 BGP 설정을 오버라이드
  • CiliumBGPPeerConfig: 타이머, eBGP Multihop, Graceful Restart 등 공통 피어 설정
  • CiliumBGPAdvertisement: 광고할 대상(PodCIDR, Service LoadBalancerIP/ClusterIP) 선택

FRR 라우터 및 Cilium BGP 설정

bash
# Router (/etc/frr/frr.conf)
router bgp 65000
 bgp router-id 192.168.10.200
 neighbor CILIUM peer-group
 neighbor CILIUM remote-as external
 neighbor 192.168.10.100 peer-group CILIUM
 neighbor 192.168.10.101 peer-group CILIUM
 neighbor 192.168.20.100 peer-group CILIUM
systemctl daemon-reexec && systemctl restart frr
yaml
# kubectl label nodes k8s-ctr k8s-w0 k8s-w1 enable-bgp=true
apiVersion: cilium.io/v2
kind: CiliumBGPAdvertisement
metadata:
  name: bgp-advertisements
  labels:
    advertise: bgp
spec:
  advertisements:
    - advertisementType: "PodCIDR"
---
apiVersion: cilium.io/v2
kind: CiliumBGPPeerConfig
metadata:
  name: cilium-peer
spec:
  timers:
    holdTimeSeconds: 9
    keepAliveTimeSeconds: 3
  ebgpMultihop: 2
  gracefulRestart:
    enabled: true
    restartTimeSeconds: 15
  families:
    - afi: ipv4
      safi: unicast
      advertisements:
        matchLabels:
          advertise: "bgp"
---
apiVersion: cilium.io/v2
kind: CiliumBGPClusterConfig
metadata:
  name: cilium-bgp
spec:
  nodeSelector:
    matchLabels:
      "enable-bgp": "true"
  bgpInstances:
    - name: "instance-65001"
      localASN: 65001
      peers:
        - name: "tor-switch"
          peerASN: 65000
          peerAddress: 192.168.10.200
          peerConfigRef:
            name: "cilium-peer"

Cilium BGP는 Speaker 역할로 경로를 광고하며, 노드 자체의 기본 게이트웨이가 라우터를 향하도록 설정되어 있어야 양방향 통신이 완성됩니다. 대규모 클러스터에서는 kube-apiserver 부하를 줄이기 위해 --set bgpControlPlane.statusReport.enabled=false가 권장됩니다.

LoadBalancer IP 광고 & Traffic Policy (Cluster vs Local)

yaml
apiVersion: cilium.io/v2
kind: CiliumBGPAdvertisement
metadata:
  name: bgp-advertisements-lb-exip-webpod
  labels:
    advertise: bgp
spec:
  advertisements:
    - advertisementType: "Service"
      service:
        addresses:
          - LoadBalancerIP
      selector:
        matchExpressions:
          - { key: app, operator: In, values: [ webpod ] }
  • externalTrafficPolicy: Cluster: 매칭되는 Pod가 없는 노드(예: k8s-ctr)도 라우터에 경로가 등록되어, 1차 수신 후 다른 노드로 재라우팅되는 추가 홉이 발생합니다.
  • externalTrafficPolicy: Local: 실제 매칭 Pod가 존재하는 노드만 라우터에 경로가 등록되어 eth1으로 들어온 패킷이 바로 해당 노드의 lxc 인터페이스로 전달됩니다.
