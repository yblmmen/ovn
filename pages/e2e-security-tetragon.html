End-to-End Security (WireGuard, TLS) & Tetragon

Zero Trust 구현을 위한 WireGuard 노드 간 암호화(cilium_wg0), Envoy 기반 TLS Inspection(중간자 복호화 검사), eBPF 런타임 보안 솔루션 Tetragon을 정리합니다.

Cilium WireGuard 암호화

기본 Pod 간 평문 통신을 암호화해 패킷 스니핑을 방어합니다. 활성화하면 각 노드에 cilium_wg0 인터페이스가 생성되고, 다른 노드와 UDP 51871 포트로 WireGuard 피어를 맺어 모든 크로스노드 Pod 트래픽을 암호화합니다.

bash
helm upgrade cilium cilium/cilium --version 1.18.1 --namespace kube-system --reuse-values \
  --set encryption.enabled=true --set encryption.type=wireguard

kubectl exec -it -n kube-system ds/cilium -- cilium encrypt status
# Encryption: Wireguard | Interface: cilium_wg0 | Number of peers: 2
wg show

Cilium TLS Inspection

HTTPS 통신 내부를 검사하기 위해 Cilium Envoy가 합법적인 중간자(MITM) 역할을 수행합니다. 사설 CA 인증서를 생성해 Pod 신뢰 저장소에 넣고, CNP의 terminatingTLS와 originatingTLS를 설정하면 Client→Envoy 구간을 복호화해 L7 정책 검사 후 다시 암호화해 외부 서버(httpbin.org)로 전달합니다.

yaml
apiVersion: cilium.io/v2
kind: CiliumNetworkPolicy
metadata:
  name: l7-visibility-tls
spec:
  endpointSelector:
    matchLabels:
      class: mediabot
      org: empire
  egress:
    - toFQDNs:
        - matchName: httpbin.org
      toPorts:
        - ports:
            - port: "443"
              protocol: TCP
          terminatingTLS:
            secret:
              name: httpbin-tls-data
              namespace: kube-system
          originatingTLS:
            secret:
              name: tls-orig-data
              namespace: kube-system
          rules:
            http:
              - {}

Tetragon (eBPF 런타임 보안)

Tetragon은 Cilium 팀이 만든 eBPF 기반 런타임 보안 솔루션으로, 커널 시스템콜과 프로세스 실행 행위(예: curl, cat /etc/passwd, touch /tmp/aa)를 실시간으로 감지합니다.

bash
helm repo add cilium https://helm.cilium.io
helm repo update
helm install tetragon cilium/tetragon -n kube-system

kubectl exec -ti -n kube-system $POD -c tetragon -- tetra getevents -o compact --pods xwing
